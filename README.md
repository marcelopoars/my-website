# Marcelo Pereira — Portfólio

Este é o código-fonte do meu site pessoal, desenvolvido com Next.js 15, React 19 e Tailwind CSS 4.

## Scripts principais

- `npm run dev`: inicia o servidor local
- `npm run build`: build de produção
- `npm run format`: formata com Prettier
- `npm run check`: roda lint, prettier e typescript

## Deploy

- Hospedado na [Vercel](https://vercel.com)
- Variáveis de ambiente são gerenciadas via painel da Vercel

## Stack

- Next.js App Router
- React 19
- Tailwind CSS 4
- Radix UI (via shadcn/ui)
- ESLint + Prettier (Rocketseat config)
